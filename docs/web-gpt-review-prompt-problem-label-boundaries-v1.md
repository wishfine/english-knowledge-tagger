# 网页版 GPT：问题标签释义/边界审稿提示词

请作为中国初中英语教研老师，审阅附件中的《18 个问题标签：初中英语教师边界草案 v1》以及对应的 prompt clarification JSON。

## 审稿目标

只审查以下内容，不重新设计 taxonomy：

1. 释义是否符合初中英语语法、词汇和语篇教学口径；
2. 必要条件是否足够明确，DS 能否据此稳定判断；
3. 是否漏掉常见正例或错误纳入常见反例；
4. 共标和排除条件是否互相矛盾；
5. 严格语法与本项目操作口径不一致时，单独指出，不要擅自改掉项目口径。

## 项目固定口径

- 一个小题可以合理共标多个知识点；不是唯一主考点不能作为删除理由。
- 只有题干、选项、答案或解析直接依赖该知识点时才判定为正例。
- 父题材料中自然出现的词或结构，不足以触发当前小题标签。
- 题面、图片或音频关键内容缺失，应记为 `input_status=insufficient`，不直接判定标签定义错误。
- `be confident that...` 在本项目中，若题目明确考查该内容从句，允许归入 `that 引导宾语从句`。
- `No smoking/No parking` 在公共标识或明确禁止语境下，允许归入 `祈使句否定形式`，并可与“禁止/警告”共标。
- 现在进行时表已安排的将来动作，本轮按项目分工归入一般将来时相关标签。

## 优先审阅标签

请优先详细审阅这 8 个：

1. 转化法
2. 现在完成时与过去完成时的区别
3. 互联通讯
4. 动词过去式变化规则
5. 现在进行时的定义/判定
6. that 引导宾语从句
7. 连接代词 wh-ever 引导宾语从句
8. 祈使句否定形式

其余 10 个做快速一致性检查。

## 输出格式

请严格输出 JSON 数组，不要输出 Markdown 表格。每个对象包含：

```json
{
  "label": "原标签名",
  "verdict": "accept | revise | conflict",
  "semantic_correct": true,
  "missing_positive_boundaries": [],
  "missing_negative_boundaries": [],
  "contradictions": [],
  "suggested_wording": "仅在确有必要时给出完整替代措辞",
  "examples": [
    {"text": "正例或反例", "should_match": true, "reason": "简要理由"}
  ],
  "notes": "不要擅自改变项目固定口径"
}
```

如果只是措辞可以更清楚，`verdict` 用 `accept`，不要为了风格重写；只有会造成系统性误判时才用 `revise`。如果严格语法与项目操作口径存在冲突，用 `conflict` 并说明两套口径的差异。
