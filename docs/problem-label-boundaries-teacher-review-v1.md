# 18 个问题标签：初中英语教师边界草案 v1

状态：`draft_for_review`。本文件只记录教师口径和实验规则，不覆盖教师原始 CSV，也不直接改动任何数据。

## 1. 统一判定原则

1. 当前小题的题干、选项、答案或解析必须显示该知识点直接参与作答；父题材料中自然出现，不足以单独触发标签。
2. 一个小题可以同时满足多个知识点。不是唯一主考点，不能作为删除理由。
3. 题面、图片或音频关键内容缺失时，记为 `input_status=insufficient`，不把数据缺失误当作标签定义错误。
4. “出现词/结构”与“题目考查词/结构”必须区分。

## 4. 需要特别保持的三个教师判断

### 4.1 `that` 从句

按严格语法，形容词后的内容从句常被称为 adjective complement；但当前 taxonomy 没有单独的“形容词补足语”叶子。因此在本项目中，若题目明确考查 `be sure/confident/glad/afraid + that 从句`，沿用 `that 引导宾语从句` 的操作归类；真正的主语从句和表语从句仍排除。

### 4.2 `No + V-ing`

它严格说是公共标识中的禁止表达，不是典型的 `Don't + 动词原形` 祈使句。由于现有教师释义已把它纳入该标签，暂时保留，但必须要求“标识/规则/禁止语境”，并允许与“禁止/警告”共标。

### 4.3 `现在进行时表将来`

这是现在进行时的真实语法用法，但当前标签分工已经把“按计划的将来动作”交给一般将来时相关标签。为了保持池内互斥，当前实验继续执行该分流；若以后要改成完整时态用法标签，应另开版本，不在本轮隐式改变。
